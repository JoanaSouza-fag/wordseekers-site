# WordSeekers — Site do jogo RPG

Projeto Angular 20 (standalone) do site do jogo educativo WordSeekers.

## GitHub Codespaces
1. Extraia os arquivos para a raiz do repositório.
2. No terminal: `npm install`
3. Execute: `npm start`
4. Abra a porta 4200 do Codespaces.

## Produção
`npm run build` gera os arquivos de distribuição (para hospedagem com servidor web).

## Conteúdo
História, 16 cidades, manual, cinco espaços da equipe e extras recolhíveis (galeria, quiz e FAQ).
As imagens em `public/assets/` são recursos do projeto do jogo.
